Escalation deadline sets

Mode: {% if production %}production{% else %}demo (SYNTHETIC){% endif %}. A deadline set says, per severity level of one incident-policy version (plus "unclassified"), which roles must be escalated to within how many minutes of the report. An empty list means "no clocked escalation at this level". The values belong to the founder and safety; the platform records them and their approvals and never supplies them. Active = the highest version approved by safety and the founder for the active incident policy; a withdrawn active version leaves none. Production uses only an owner-approved set. Nothing is sent, paged or notified: overdue escalations are only shown in the exception inbox and on the incident page.
